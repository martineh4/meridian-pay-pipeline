# Meridian Pay Pipeline

Sample Node.js/Express API with a GitHub Actions CI/CD pipeline demonstrating SOC 2 supply chain security controls.

## Local development

```bash
npm install
npm test          # run Jest unit tests
npm run dev       # start with nodemon (requires nodemon globally or npx)
node src/index.js # start without hot-reload
```

## API endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | /health | Health check |
| POST | /payments | Create a payment |
| GET | /payments/:id | Get payment by ID |

## CI/CD pipeline

The `.github/workflows/pipeline.yml` pipeline runs on every push to `main` and on pull requests. It enforces four SOC 2 supply chain security controls in sequence:

1. **test** — Jest unit tests with coverage
2. **vulnerability-scan** — npm audit + Trivy filesystem scan
3. **build-and-push** — Docker image pushed to GHCR
4. **sbom** — CycloneDX SBOM generated by Syft
5. **sign** — Cosign keyless signing + SBOM attestation

See `docs/pipeline.md` for full auditor guidance.
